# Target App

**Owner**: Member B

The Target App is the sample full-stack application that serves as the live canvas for the multi-agent pipeline. It consists of a REST API backend (FastAPI or Express) and a React + Vite frontend, backed by a local SQL database (SQLite for development, PostgreSQL for production).
All code generated, reviewed, and validated by the agent pipeline is applied here — making it a living demonstration of the pipeline's end-to-end capabilities.
The app includes seed data, basic authentication, and a simple CRUD interface so that the agents always have a realistic codebase to extend and improve.
