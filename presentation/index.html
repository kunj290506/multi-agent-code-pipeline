01 • Industry Context

The Breakdown of Single-Prompt AI Coding

Why monolithic LLM prompts fail on real-world software engineering tasks.

The Failure Modes of Monolithic Prompts

  • Hallucinated Dependencies & Schemas:

    Single prompts invent non-existent APIs, incorrect foreign keys, and outdated framework methods.

  • Codebase Blindness (No RAG Context):

    LLMs have zero awareness of project-specific utilities, existing models, or architecture conventions.

  • Incomplete Placeholders & TODOs:

    Monolithic outputs frequently produce "// Add logic here" or write dead code with no UI wiring.

  • No Verification or Security Gate:

    Generated dangerous functions (eval(), SQL injections, hardcoded secrets) pass directly to execution.

The Multi-Agent Orchestration Paradigm

  • Decomposed Specialization:

    Division of labor across 5 purpose-built microservices: Planning, RAG Context, Database, CodeGen, & Review.

  • Targeted RAG Semantic Retrieval:

    ChromaDB vector embeddings index existing workspace files and inject exact code snippets before generation.

  • Autonomous Self-Healing Loop:

    The Reviewer agent tests code via AST and security checkers, rejecting errors back to CodeGen for up to 5 automated retries.

  • Deterministic Whole-Project Scaffolding:

    Entrypoint index.html, styling style.css, and runtime app.js are generated and cleanly integrated.

04 • Engineering Deep Dive

Pipeline Hardening & Permanent Formatting Fix

Solving the notorious LLM double-escaping trap and architecting production stability.

The "Missing CSS" Root Cause & Permanent Fix

Before (Broken Double-Escaping):
// LLM outputs literal escaped characters inside JSON:
<link rel=\"stylesheet\" href=\"style.css\">

// Browser interprets as literal quotes:
GET /%22style.css%22 -> HTTP 404 Not Found!
Result: Unstyled page with raw "\n" text nodes everywhere
Permanent Architectural Fix:
// 1. CodeGen Prompt Rules 10-12 strictly forbid double escaping
// 2. _sanitize_generated_code() normalizes quotes and attributes
// 3. Regex verifies & adds missing rel="stylesheet"
// 4. Auto-fallback supplies responsive modern CSS if missing
Result: HTTP 200 OK styling loaded instantaneously!

Resilience & High-Performance Execution

  • Dual Groq Fallback Engine:

    Primary model openai/gpt-oss-120b with automatic switch to openai/gpt-oss-20b on 429 rate limit or capacity constraints.

  • LRU Prompt Cache:

    In-memory cache with thread-safe lock returns repeated prompts in 0ms, saving API quota and eliminating redundant compute.

  • Security AST Inspection:

    Reviewer parses Python AST and checks JavaScript nodes, instantly catching forbidden primitives (eval, exec, SQL injection vectors).

  • Ephemeral Process Management:

    Generated web applications are assigned dynamic free OS ports and served via cross-platform subprocesses with zero port collisions.
